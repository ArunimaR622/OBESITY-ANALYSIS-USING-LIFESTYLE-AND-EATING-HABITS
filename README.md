# OBESITY-ANALYSIS-USING-LIFESTYLE-AND-EATING-HABITS
A Data-Driven Study on Lifestyle Factors Influencing Obesity
Project Overview

This project explores how daily habits — such as diet, physical activity, sleep, transportation, and high-calorie food consumption — contribute to obesity levels.
Using a synthetic dataset, we perform descriptive and exploratory analysis to uncover relationships between lifestyle patterns and health risk indicators.

The project includes data preprocessing, feature engineering, univariate, bivariate & multivariate analysis, and visualizations.
